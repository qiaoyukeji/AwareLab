# AwareLab 品牌资产

图形标识由**钓钩**与**两道信号弧**组成：钓钩代表演练里那封邮件、那个仿冒页；
信号弧代表平台真正的动作——信标面上报与被识别。深色方砖 + 白钩 + 青弧，缩到
16px 仍然读得出来，这是选形的硬性前提。

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `awarelab-mark.svg` | 主标识（带方砖底），应用内顶栏、登录页、README |
| `awarelab-mark-mono.svg` | 单色版，用 `currentColor`，适合印刷、水印、终端与深色底 |
| `awarelab-logo.svg` | 横版组合（标识 + 字标 + 副标），浅色背景 |
| `awarelab-logo-on-dark.svg` | 横版组合，深色背景 |
| `awarelab-icon-1024.png` | 应用图标概念稿（栅格），可裁成 512/192/48 等平台图标尺寸 |
| `../web/public/favicon.svg` | 浏览器标签页图标，按小尺寸加粗了笔画，**不要**放大用作主标识 |

## 颜色

| 名称 | 值 | 用处 |
| --- | --- | --- |
| Ink | `#15202b` | 字标、正文、方砖深色渐变起点 `#1c2b39` → `#0d151d` |
| Accent | `#0f766e` | 方砖描边、字标 "Lab"、界面主色 |
| Accent 2 | `#12897f` | 信号弧 |
| On-dark | `#5eead4` | 深色底上的 "Lab" |

标识里的白钩在任何底色上都保持 `#ffffff`，不要改成主色。

## 使用规则

- 最小尺寸：方砖标识 16px，横版组合宽度 120px；再小请只用方砖。
- 净空：四周留出不小于标识高度 1/4 的空隙，不要贴边、不要压在其他元素上。
- 不要拉伸变形（等比缩放）、不要加投影/描边/渐变重绘、不要把钩换成别的形状、
  不要把信号弧挪到钩的另一侧。
- 不要给标识加文字改写副标；需要标语请用 `awarelab-logo.svg` 里那一行。
- 单色场景（印刷、水印、SVG 内联）请用 `awarelab-mark-mono.svg` 并指定颜色，
  不要复制主标识后手动改填充。

## 与界面的关系

顶栏与登录页用 `web/src/ui/BrandMark.vue`（内联同一份路径数据，避免运行时去请求
静态资源），标签页图标用 `web/public/favicon.svg`。两者几何一致，改标识请同时改
这两处与本目录的 SVG。
