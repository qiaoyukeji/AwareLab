## 1. 测什么，怎么判

四个维度不是并列的功能清单，而是四种"会出事的方式"：

| 维度 | 关注的问题 | 判定口径 |
| --- | --- | --- |
| 安全性 | 没授权的人拿不到什么；授权一出窗口平台是否立刻收手；每个高危动作能不能追到人 | 任一失败即 P0，不带病发布 |
| 功能正确性 | 接口在边界入参下的行为是否与声明一致，不谎报成功、不静默吞掉 | 任一失败即缺陷，必须留回归断言 |
| 业务流程 | 登记授权 → 建页 → 建站 → 签链接 → 上钩 → 出证据这条链能否走通，且中途状态与库里一致 | 链路断裂即 P0，状态失真按 P1 |
| 人性化与文案 | 操作员看得懂、演练对象不被文案泄密、数字不会"看着像算错" | 泄露演练身份按 P1，其余按 P2 |

**中性文案**是本产品特有的一条判定：演练对象能看到的每一屏（仿冒页、提示页、跳转页）都不许出现「演练 / 授权 / 采集 / 站点 / 名单」这类内部词。出现一次，当场作废这次演练，所以它同时是安全用例（TC-S-11）和文案用例（TC-U-05）。

四个执行器、五种跑法，本轮合计 **512 条判定**（其中产品级独立用例 73 + 208 + 24，种子回归是 208 条在真实数据上的第二次跑）：

| 现网冒烟 | `node server/scripts/smoke.mjs` | 正在运行的生产实例，**全程只读** | 24 | 部署后能不能真用、安全开关有没有被改关 |

QA 套件的过滤开关（排查单个用例时用）：

```
node server/scripts/qa.mjs --only=S,F        # 只跑安全 + 功能（S/F/P/U）
node server/scripts/qa.mjs --case=TC-S-11    # 只跑指定用例，逗号分隔可多个
node server/scripts/qa.mjs --keep            # 保留隔离实例与 .qa 现场，便于手工排查
```

## 4. 隔离与红线

测试脚本会真实建站监听、真实提交凭证、真实吊销授权，所以隔离不是可选项：

1. **绝不写生产库**：QA 与自检各自在自己的 `.qa` / `.selftest` 目录生成配置与 SQLite 文件，只有 `smoke.mjs` 连生产实例，且只做 GET 与采集面 Host 头探测。
2. **凭据不出机器**：隔离实例的口令随机生成、不打印；文档、日志、聊天里管理面板路径一律掩码。
3. **端口避让**：4222 / 4111 / 4321 与生产 7778 不冲突；采集面每个用例族独占一个端口，否则限流计数和"谁把谁挤掉了"会互相污染。
4. **不干扰真实演练**：种子回归遇到"存在非本脚本登记的生效授权"时，把会吊销授权的 3 条用例判为 SKIP 而不是跑掉——宁可少跑三条，不能把操作员的在跑演练停掉。
5. **现场不进仓库**：`server/.qa`、`server/.selftest`、`server/.functional`、`server/data` 均在 `.gitignore` 内。

## 9. 用例维护规则

1. **断言跟着文案走**。界面改名把 e2e 打挂过两次（`白名单` → `授权名单`，再到中性化后的「页面不存在」）。产品文案变更必须同批改断言，且断言只认关键语义，不认整句。
2. **每条 P0/P1 缺陷必须留下回归断言**，只改代码不加断言的整改不予验收（整改方案 §6 准出规则）。本轮实例：中文附件名乱码修完后，TC-P-04 同时断言附件名和中文输入字段名。
3. **演练对象可见的文案，断言写成"不含内部词"**，而不是"等于某句话"——后者会让下一次改动顺手把「授权」写回访客页面。
4. **不在生产库上做写测试**；需要真实数据形状时用只读副本（`VACUUM INTO`），这就是种子回归存在的原因。
5. **新增管理端点必须进 TC-S-01 的未登录清单**，否则新接口会默认没有鉴权覆盖。
6. **用例失败先分清是产品缺陷还是夹具问题**。本轮 TC-U-05 第一次失败是夹具（关闭态站点根本没有监听），TC-P-04 第二次失败才是真缺陷（latin1 解码头）。结论写进测试报告，不要靠放宽断言蒙过去。
7. **`qa.mjs` 里新增 `tc()` 必须同批在本文档登记**（编号、预期、断言要点）。v1.2.0 收口时做过一次对账：脚本里 86 条、文档只列到 75 条，M2/M3 那 11 条（TC-S-29~32、TC-F-19~23、TC-P-13、TC-U-16）有断言没有条目——用例只在代码里存在，就等于没有验收标准。对账方法：拿 `grep -o "tc('TC-" qa.mjs` 与本文档的编号列比差集。
